# Сторож «Мʼясного Барона»

Раз на 10 хвилин з 8:00 до 21:00 за Києвом перевіряє, чи живі сайт
meat-baron.kh.ua і API з ботом. Якщо щось лягло — пише власнику в Telegram.

Окремий відкритий репозиторій, бо код сайту закритий, а запуски GitHub Actions
у відкритих репозиторіях безкоштовні без ліміту хвилин. Коду сайту тут немає.

Секрети (Settings → Secrets and variables → Actions): `BOT_TOKEN` і `OWNER_ID`.
Перевірити руками: Actions → «Сторож» → Run workflow.
